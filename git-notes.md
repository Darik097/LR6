# Краткие заметки по Git

- Рабочее дерево содержит редактируемые файлы.
- Индекс хранит подготовленное содержимое следующего коммита.
- Коммит фиксирует снимок проекта, автора, время и сообщение.
- Ветка — перемещаемый указатель на коммит; HEAD указывает на текущую ветку.

## Безопасный рабочий цикл

1. Проверить состояние: `git status`.
2. Изучить изменения: `git diff`.
3. Подготовить нужные файлы: `git add <файл>`.
4. Проверить индекс: `git diff --cached`.
5. Зафиксировать результат: `git commit -m "Содержательное сообщение"`.
6. Получить изменения: `git pull --ff-only`, отправить: `git push`.

`git fetch` обновляет ссылки на удалённые ветки, не изменяя рабочее дерево.
`git pull` получает изменения и интегрирует их в текущую ветку.
`git revert` создаёт обратный коммит и сохраняет историю; `git reset` перемещает указатель.
